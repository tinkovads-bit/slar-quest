# Квест: СЛАР — Практичне заняття 3

Інтерактивний квест з лінійної алгебри для студентів університету.  
Один файл `index.html` — більше нічого не потрібно.

---

## Як розмістити на GitHub Pages

### Крок 1 — Створити репозиторій
1. Зайдіть на [github.com](https://github.com) і увійдіть у свій акаунт
2. Натисніть кнопку **+** → **New repository**
3. Назва: наприклад `slar-quest` (лише латинські літери та дефіс)
4. Visibility: **Public** (обов'язково — інакше GitHub Pages не працює)
5. Натисніть **Create repository**

### Крок 2 — Завантажити файл
1. На сторінці репозиторія натисніть **Add file → Upload files**
2. Перетягніть або виберіть файл `index.html`
3. Унизу натисніть **Commit changes**

### Крок 3 — Увімкнути GitHub Pages
1. Перейдіть у **Settings** (вкладка вгорі сторінки репозиторія)
2. У лівому меню знайдіть розділ **Pages**
3. У полі **Source** оберіть `Deploy from a branch`
4. Гілка: `main`, папка: `/ (root)`
5. Натисніть **Save**

### Крок 4 — Отримати посилання
Через 1–3 хвилини з'явиться зелений блок з посиланням:

```
https://ВАШ-ЛОГІН.github.io/slar-quest/
```

Це посилання даєте студентам.

## Функції

- 🗺️ Карта завдань з індикатором прогресу
- 📐 Системи рівнянь у правильному математичному записі (з фігурною дужкою)
- 💡 Підказки до кожного підзавдання
- ✅ Миттєва перевірка: поля підсвічуються зеленим / червоним
- 🏆 Екран результатів з балами по кожному завданню
- 📄 Кнопка «Завантажити PDF» — студент отримує файл зі всіма своїми відповідями та балами
- 🎉 Конфеті при результаті ≥ 80%

## Технічні деталі

- Один файл `index.html`, без фреймворків, без залежностей
- PDF генерується через [jsPDF](https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js) (CDN, завантажується лише при натисканні кнопки)
- Працює на будь-якому сучасному браузері (Chrome, Firefox, Safari, Edge)
- Адаптивний дизайн: працює на смартфонах та планшетах
